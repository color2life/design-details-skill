# AI tells

Habits that make a page look generated. Each one has a move to make instead. These are defaults, not laws: if the brief asks for it, or an inspected reference shows it working for a reason that applies here, it can stay. Say why.

## Looks every model reaches for

| Tell | Do instead |
|---|---|
| Cream or beige background, a serif headline, a terracotta or muted green accent | Take the palette from the chosen reference and the brand. Commit to a strong colour when the brief allows. |
| Near-black page with a neon accent and glowing blobs | Dark only when the reference or brand is dark; light it with real imagery, not glow. |
| Purple-to-blue gradients, indigo or violet "trust" colours | A brand colour, or one confident accent from the reference system. |
| Newspaper hairlines everywhere with monospace labels | Rules only where they separate real groups. Mono only for actual code or data. |
| The SaaS card kit: identical rounded cards, soft grey shadows, an icon on top of each | Let the content set the shape: a list, a table, an image-led row, one large item and smaller ones. |
| Glass panels, gradient text, glow on hover | Plain, well-set type on a solid surface. Effects only where they explain something. |
| Inter, Roboto or Poppins for everything, or the same trendy display serif | Choose type for what the reference's type does: its proportions, weight and contrast. |

## Small marks of a template

| Tell | Do instead |
|---|---|
| A small capitalised label above a heading ("FEATURES", "HOW IT WORKS", "IT'S NOT IN YOUR HEAD") | Delete it. The heading says what the section is. |
| One word of a headline in italics or a different colour | Let the whole headline carry the weight. |
| Numbered section markers (01, 02, 03) when nothing is a sequence | Numbers only for real steps. |
| Middle dots between meta words ("Fast · Simple · Secure"), arrows glued to every link | Plain words; one arrow on the one link that moves forward, if any. |
| A coloured stripe down the left edge of cards, or hard offset shadows | Use space and alignment to group. |
| Cards inside cards | One level of surface. |
| Emoji or unicode symbols used as icons | One real icon set, consistent stroke, or no icons. |
| Pill badges and status dots that mean nothing | Remove them. |

## Page shapes that feel generated

| Tell | Do instead |
|---|---|
| Hero, three feature cards, a stats row, a testimonial, a call to action, in that order | Order sections by what this visitor needs to know to act. Follow the reference's structure. |
| The default split: headline and button on the left, image in a box on the right | Let type and image interact: the headline crosses the photo, wraps around it, sits inside it, or is the image. Use the split only when a reference's move needs it. |
| Every section a centred heading over a neat grid | Vary the placement: off-axis headings, text set low or to one side, a section that is one huge line. |
| Safe type sizes everywhere | Give the sizes real contrast where the idea needs it. Scale is one tool, not the only one. |
| A giant word, a few small lines and one button: the generated "bold" poster on every page | Pick the kind of bold the brief needs (image, product, object, structure, quiet, type). Use poster scale only when the words themselves are the idea. |
| A giant number hero ("10x faster", "99.9%") | Lead with the most characteristic thing in this business: the product, the place, the work. |
| Every section fades up as you scroll | Motion that is the section's layout idea (cards stacking, panels opening, words lighting up), in a few sections only. |
| A drawn fake browser window or fake app screen | A real screenshot of the real product, or an honest placeholder. |
| A newsletter signup as the last thing on every page | End with the action that matters for this page. |
| Long copy blocks, three bullet points under everything, extra explanation | Cut by half. Say it once. |
| A section added because a template usually has one | Every section answers a question the visitor has. |

## Copy tells

- Words that fit any company: seamless, elevate, unlock, empower, revolutionise, cutting-edge, next-level, delve.
- Headlines that are slogans rather than statements ("The future of work, today").
- Invented proof: numbers, logos, testimonials or awards that the designer did not supply.
- Em dashes in every sentence.

## The test

Cover the logo. Could this page belong to a competitor with a find-and-replace on the name? If yes, it has no idea of its own yet. Go back to the reference and the brief and find what only this business has.

Then the second test: removing every tell leaves a clean page, not a good one. A page with no tells and no bold move is still a template.
